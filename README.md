# 📊 Bank Marketing Insights Dashboard

## 🚀 Project Overview
This project focuses on analyzing customer data from a bank marketing campaign to identify patterns influencing **term deposit subscriptions**.  

An interactive dashboard was built using **Power BI** to visualize key insights and support data-driven decision-making.

---

## 🎯 Objective
To understand:
- Which customers are more likely to subscribe  
- How demographics influence customer behavior  
- Key factors affecting marketing campaign success  

---

## 📁 Dataset
- Bank Marketing Dataset  
- Contains customer details such as:
  - Age, Job, Marital Status  
  - Education, Loan Status  
  - Balance, Contact Information  
  - Subscription outcome (Yes/No)

---

## 🛠 Tools Used
- **Power BI** – Data visualization & dashboard creation  
- **Excel** – Data cleaning & preprocessing  

---

## 📊 Dashboard Features

### 🔹 KPI Cards
- Total Customers  
- Subscribers  
- Subscription Rate  

### 🔹 Visualizations
- 📈 Subscription Status (Pie Chart)  
- 📊 Job vs Subscription (Bar Chart)  
- 📊 Education vs Subscription (Column Chart)  
- 🎯 Subscription Rate (Gauge Chart)  

### 🔹 Filters (Slicers)
- Marital Status  
- Job Type  
- Education Level  

---

## 💡 Key Insights
- Majority of customers did not subscribe to the term deposit  
- Higher education customers show better response rates  
- Job category influences subscription behavior  
- Customer demographics play a key role in decision-making  

---

## 📌 Outcome
This project demonstrates how data visualization can:
- Improve marketing strategies  
- Identify high-potential customers  
- Support business decision-making
